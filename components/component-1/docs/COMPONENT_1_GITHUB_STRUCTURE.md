# Proposed Component 1 repository structure

Copy only repository-overlay/components/component-1 into a clean group checkout. Do not copy this output folder wholesale: upstream-readonly, tools, validation-state and the outer absolute-path provenance manifest are private audit material.

```
components/component-1/
  README.md
  .gitignore
  app/
    frontend/{src,contracts,public/lab-fixtures,tests}/
    runtime/{PP1_READINESS_20261022,PP1_STAGE_E_RESEARCH_CORE,...}/
    portable_runtime.py
    launcher.py
    requirements-cpu.txt
    setup.ps1  start.ps1  stop.ps1
    verify_portable.py  build_portable_manifest.py
    PORTABLE_SOURCE_MANIFEST.json
  research/
    workspace/PP1_READINESS_20261022/<original research sources>/
    colab/{01_NOTEBOOKS,09_RUNTIME,requirements_colab.txt}/
  contracts/{schemas,examples}/
  docs/
  provenance/SOURCE_PROVENANCE.json
```

All app-internal relative relationships remain unchanged. New research reference sources are outside app so they do not silently change its runtime imports. Model weights and venue files must not be committed; ordinary controlled startup is lazy and does not require weights. .venv, node_modules, dist and runtime-state are regenerated by setup/runtime. Regenerated stage manifest reflects source exclusions, not a new research mechanism.

Full training/evaluation and independent scientific comparison source is retained beyond the portable demo. Historical generated outputs are summarized in documentation; they are not falsely represented as freshly reproduced results. No root group README, requirements or another member's source is replaced.

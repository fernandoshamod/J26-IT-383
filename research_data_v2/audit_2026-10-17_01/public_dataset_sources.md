# Public source assessment (checked 2026-10-17)

No external dataset was downloaded in this audit. The existing local Yelp-named samples were inspected as local files; their exact acquisition path and license acceptance are not documented here. Therefore their rows are **public-source-shaped but row lineage and reuse permission are not independently verified**.

| Source | Accessibility / usage | Relevant information | Coverage / freshness | Missing for PlanoVision | Decision |
|---|---|---|---|---|---|
| [Google Local Data (2021)](https://mcauleylab.ucsd.edu/public_datasets/gdrive/googlelocal/) | Public UCSD catalog, including sample and state files. Catalog asks users to cite papers; no blanket reuse license was identified on the accessed page. Verify rights before redistribution. | Business ID, name, category, address, coordinates, average rating, review count, review text in separate files. Potential catering, photo, event-service keyword filters require validation. | US only; listed data ends September 2021. Large full files; do not download wholesale. | Actual event quotations, inventory, availability, contracts, collaboration, incidents, operating radius. The metadata price marker is **not** a service quote. | Candidate research source after license review; use small filtered lawful extract only. |
| [Yelp Open Dataset](https://business.yelp.com/data/resources/open-dataset/) | Named public page returned an access error from this audit environment. Current dataset download terms/license could not be verified here. Do not infer permission from local CSV filenames. | Local [business sample](../../dataset/yelp_business_1000.csv) and [review sample](../../dataset/yelp_reviews_1000.csv) expose IDs, categories, stars, review counts and review text. | Local samples are only 1,000 rows each; full current coverage and extract date remain unverified. | Service prices, bookings, actual availability, operational incidents, pair collaboration. Business price level, if present elsewhere, is not an event quote. | Prefer local data for **auditing only** until original license and extraction provenance are documented. |
| [OpenStreetMap](https://www.openstreetmap.org/) | Public ODbL geodata with attribution and share-alike obligations for qualifying derived databases; see [official copyright](https://www.openstreetmap.org/copyright). Respect API usage policy; no bulk query here. | POI name, geometry, address and relevant mapped tags where present. | Global and continually edited; individual POI timestamps/accuracy vary. | Ratings, reviews, quotations, booking status, collaboration, validated capacity. | Useful later for location cross-check, not risk or availability ground truth. |

**Joining policy:** Keep source-specific IDs and license fields. A shared name or nearby coordinate is only a candidate match, not a verified identity. Require address/geometry/category agreement plus manual review and preserve both original IDs. Never merge Yelp, Google and OSM rows automatically or transfer a rating across uncertain matches. No public source above supplies the operational outcome labels needed to validate real vendor failure prediction.

Other official context: [Yelp developer overview](https://docs.developer.yelp.com/docs/getting-started) describes an API, which is distinct from the open dataset and has separate access conditions. No API data was requested.

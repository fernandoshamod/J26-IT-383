# PP1 supervisor viva — 15 grounded questions and answers

1. **What is the one ML model you are presenting?** The existing saved Random Forest classifier for Low, Medium and High review-derived vendor labels. It has 100 trees and five ordered inputs. [Model status](../pp1_final_model_verification/model_status.md).

2. **What are the five inputs and their order?** `stars`, `review_count`, `collected_review_count`, `mean_review_rating`, `rating_std`. The saved artifact and backend enforce this order. [Runtime metadata](../pp1_final_model_verification/model_runtime_metadata.json).

3. **What do the target labels represent?** A deterministic rule over review mean, rating variation and collected review count. They are proxies from review data, not observed operational failures. [Model status](../pp1_final_model_verification/model_status.md).

4. **Why was 100% accuracy reported?** The reconstructed held-out labels are generated by a rule whose three inputs are among the model features. The model reproduced those labels exactly on 3,686 rows. This says nothing about measured vendor failure accuracy. [Confusion matrix](../pp1_final_model_verification/confusion_matrix.png); [limitations](../pp1_final_model_verification/limitations.md).

5. **Was the original test partition independently preserved?** No. The notebook records an 80/20 stratified split with random_state 42 and the ordered input matches current data, but original held-out IDs were not separately archived. The evaluation is a reconstruction. [Holdout details](../pp1_final_model_verification/holdout_details.json).

6. **Did you retrain the model for PP1?** No. The existing artifact was loaded and used for inference only; the artifact hash remained unchanged. [Source hashes](../pp1_final_model_verification/source_hashes.csv).

7. **How do you know FastAPI uses the saved artifact?** The dynamic route calls `load_risk_signals`, whose verified loader checks the artifact SHA-256 and predicts candidate vendor rows. An in-process endpoint response matched direct model predictions. [Integration trace](../pp1_final_model_verification/model_integration_trace.md); [probe](../pp1_final_model_verification/fastapi_integration_probe.json).

8. **Does the model class directly determine package rank?** No. The ranking uses a numeric rule-derived favorability score; disagreement between model class and rule label removes that score. The class is carried into the response and UI. [Integration trace](../pp1_final_model_verification/model_integration_trace.md).

9. **Are model probabilities real failure probabilities?** No. They are classifier scores over rule-generated classes and were not calibrated against operational outcomes. [Limitations](../pp1_final_model_verification/limitations.md).

10. **Does React run the model itself?** No. FastAPI runs inference. React displays class fields from the current dynamic response. Its AI Model metrics page shows saved evaluation values. [Integration trace](../pp1_final_model_verification/model_integration_trace.md).

11. **What exactly did the focused demo check show?** For the specified Wedding/Philadelphia 50-guest event it returned HTTP 200, three packages, and a top package costing LKR 305,535.41. A separate feasibility rerun returned `VERIFICATION_REQUIRED`, 10 simulation passes, 8 pending checks and no failures. [Exact response](./pp1_demo_inputs_and_outputs.json).

12. **Why is the top package not a confirmed booking?** Prices and option constraints are simulated; availability, scheduling, real capacity, vendor collaboration and venue suitability remain unverified. [Feasibility response](./pp1_demo_inputs_and_outputs.json); [dataset audit](../yelp_lineage_gap_audit/audit_summary.md).

13. **Does the compatibility score prove named vendors can work together?** No. Production compatibility scores service-category pairs, not historical or event-specific vendor pairs. [Compatibility audit](../yelp_lineage_gap_audit/compatibility_evidence_audit.md).

14. **Is the highest ranked package globally optimal?** No. The system limits candidates per service and nodes visited. The focused event flagged candidate truncation. Rank is within the examined pool. [Demo response](./pp1_demo_inputs_and_outputs.json).

15. **Why did 500 guests in Bensalem return no Catering + Entertainment package?** In V1, the cheapest capacity-eligible Catering estimate alone was LKR 2,803,335, above the LKR 1m budget; the two-service lower bound was LKR 3,001,999.68. That is a synthetic pricing/budget result, not a Random Forest failure. [Capacity/pricing audit](../yelp_lineage_gap_audit/guest_capacity_pricing_analysis.md).

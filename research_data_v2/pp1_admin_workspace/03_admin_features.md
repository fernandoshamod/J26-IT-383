# Admin Features

- Dashboard: live counts from vendor CSV, service-option loader and SQLite events; categories and model summary are loaded from backend data.
- Vendor Management: read-only search, category/location filters and pagination. No fake add/edit/delete controls.
- Service Options: category/location filters, pagination, LKR display and synthetic-data warning.
- Event Management: inspection of existing SQLite event records without changing records during the admin demo.
- AI Model Overview: accuracy, macro F1, holdout size, features and the rule-derived-label limitation.
- Report Generator: three report types, browser-generated PDF export, CSV for tabular summaries and source/disclaimer text.
- Navigation: Admin Workspace is separate from the collapsible Research & Evaluation group.

# 02 UI design changes — premium teal/ivory pass

This second redesign pass moves PlanoVision from a purple research dashboard toward a warm, commercial event-management platform.

## Design system

- Warm ivory background: `#F7F8F4`
- White cards and sidebar: `#FFFFFF`
- Deep teal primary: `#166B68`
- Soft mint surfaces: `#E8F3EF`
- Champagne gold accents: `#D6A66B`
- Warm dark text: `#344A48`
- Borders: `#E5E9E4`

No black, navy or charcoal block is used as a large page, sidebar or dashboard background.

## Composition changes

- Dashboard now leads with a warm welcome panel, real SQLite-backed event counts, upcoming event list and a useful next-step panel.
- My Events uses warm ivory event cards with visible View, Edit and Delete actions.
- Research & Evaluation is collapsed by default in the sidebar and expands on demand.
- Research Reports was replaced with an Evidence Library composition: featured methods/findings, supporting data/audit trails, metrics strip, read-only stamp, expandable evidence and source links.
- Recommendations, comparison and feasibility inherit teal status, champagne highlights, mint verification surfaces and clearer hierarchy through shared CSS.
- No imagery was added because no licensed event imagery was available; the dashboard uses a non-image editorial welcome treatment instead.

# Package generation and user-flow status

| Function | Observed implementation | Evidence and limitation |
|---|---|---|
| Dynamic generation | **Implemented.** New `USER-*` request ID; reads current synthetic options and constructs combinations at request time. | [dynamic_package_service.py](../../backend/engine/dynamic_package_service.py), [bounded_package_generator.py](../../backend/engine/bounded_package_generator.py), [focused API results](./focused_api_results.json). Search is capped at 12 candidates/service and 5,000 nodes by default. |
| Budget | **Implemented for estimated LKR prices.** Recalculates price and rejects combinations above budget; lower-bound check can reject before search. | [validation_helpers.py](../../backend/engine/validation_helpers.py), [bounded_package_generator.py](../../backend/engine/bounded_package_generator.py). Estimates are synthetic, not quotations. |
| Guest capacity | **Partial.** Catering options require simulated `max_guests >= guest_count`; non-Catering capacity is pending. | [candidate_selection.py](../../backend/engine/candidate_selection.py), [dynamic_feasibility.py](../../backend/engine/dynamic_feasibility.py), [capacity audit](../yelp_lineage_gap_audit/guest_capacity_pricing_analysis.md). |
| Location | **Implemented for exact simulated city/state.** The request location must exist in the option table. | [dynamic_package_service.py](../../backend/engine/dynamic_package_service.py), [candidate_selection.py](../../backend/engine/candidate_selection.py). Real travel/service area is not verified. |
| Service and event type | **Implemented against option rows.** Exact service-category and semicolon-token event-type matching. | [candidate_selection.py](../../backend/engine/candidate_selection.py). Original category-to-service assignment is derived; offering not confirmed. |
| Distinct vendors / feasibility | **Implemented within simulation.** Search excludes repeated vendor IDs and FAIL packages; complete combinations are checked before top-K. | [bounded_package_generator.py](../../backend/engine/bounded_package_generator.py), [dynamic_feasibility.py](../../backend/engine/dynamic_feasibility.py). Real availability, collaboration and venue remain pending. |
| Comparison | **Implemented in React.** Same-request packages can be selected and compared by cost, score, vendors, categories and pending checks. | [PackageViews.jsx](../../frontend/src/pages/PackageViews.jsx), [prior browser capture](../pp1_task6_presentation/screenshots/comparison.png). |
| Feasibility rerun | **Implemented for USER options.** Dedicated route reloads canonical option rows and rejects conflicting submitted fields. | [feasibility.py](../../backend/api/feasibility.py), [current demo rerun](../pp1_final_submission/pp1_demo_inputs_and_outputs.json). `VERIFICATION_REQUIRED` is the honest status for missing event-specific evidence. |
| Edit event and regenerate | **Implemented as session revision.** Form is prefilled; save submits a new USER request, resets comparison/feasibility state; cancel retains prior committed result. | [App.jsx](../../frontend/src/App.jsx), [EventWizard.jsx](../../frontend/src/pages/EventWizard.jsx), [FR13 browser evidence](../pp1_fr13_no_match_recovery/fr13_verification.md). No server-persisted editable event or cross-reload history. |
| No-match recovery | **Implemented for current simulations.** Diagnostics explain no category coverage vs insufficient budget and suggest priceable locations; Edit Event opens the wizard. | [coverage_diagnostics.py](../../backend/engine/coverage_diagnostics.py), [PackageViews.jsx](../../frontend/src/pages/PackageViews.jsx), [FR13 root cause](../pp1_fr13_no_match_recovery/root_cause_analysis.md). Suggestions do not guarantee a feasible complete package. |

# Compatibility and conflict integration status

**Production:** [dynamic_package_service.py](../../backend/engine/dynamic_package_service.py) calls [service_compatibility.py](../../backend/engine/service_compatibility.py), which reads 15 service-category pairs from [vendor_compatibility_matrix.csv](../../vendor_compatibility_matrix.csv). It averages known pair scores and passes that heuristic to [bounded_package_generator.py](../../backend/engine/bounded_package_generator.py) as a ranking component. Its output explicitly says `is_vendor_collaboration_evidence=False`. Unknown category pairs remain unknown; category compatibility does not filter candidate vendors.

**Standalone research:** [conflict_engine.py](../pp1_task2_conflict_engine/conflict_engine.py) checks event-specific vendor-pair evidence, scheduling and resource constraints in a separate prototype. Its [controlled evaluation](../pp1_task2_conflict_engine/evaluation_report.md) matched 12/12 hand-authored synthetic fixtures. These are **SYNTHETIC_TEST** statuses, not real conflict accuracy. The [shadow adapter](../pp1_task3_shadow_integration/shadow_adapter.py) assessed six fresh packages without changing production outcomes; all six were `VERIFICATION_REQUIRED` because event-specific evidence was missing. [Shadow report](../pp1_task3_shadow_integration/evaluation_report.md).

**Integration conclusion:** The standalone engine is **not integrated** into the active FastAPI package recommendation or React feasibility result. No call to it exists in the inspected production dynamic path. The production [dynamic_feasibility.py](../../backend/engine/dynamic_feasibility.py) leaves vendor-pair collaboration, availability, scheduling and venue suitability pending. Venue suitability belongs to the teammate's component and is **not** counted as this component's completed work.

**What would be required:** define a source-authenticated, event-scoped pair/resource/availability evidence contract; preserve unknowns; add fail/pending behavior and integration tests; only then consider production activation. Random simulated collaboration rows in V1 are not proof of real collaboration. [Compatibility evidence audit](../yelp_lineage_gap_audit/compatibility_evidence_audit.md).

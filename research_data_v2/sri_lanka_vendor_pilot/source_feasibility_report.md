This is a source and reuse audit, not a vendor verification. No directory records were imported. Public display does not establish permission for bulk copying or redistribution.

## Collection result and access evidence

- **0 records collected.** Directory bulk-use permission remains unverified.
- One bounded Overpass attempt through PowerShell and curl failed with TLS secure-channel errors; the curl attempt was also repeated outside the sandbox with the same TLS error. An integrated-browser request to the main Overpass API returned HTTP 406; a bounded query to an alternate instance returned HTTP 500. These are access failures, not evidence that no Sri Lankan vendor records exist.
- No CAPTCHA, authentication, robots rules, rate limits or access controls were bypassed. No directory listings were scraped.
- The license of OSM data is clear, but individual OSM map objects are **mapped places**, not confirmed current event vendors or available bookings. The [OSM photographer tag](https://wiki.openstreetmap.org/wiki/Tag%3Acraft%3Dphotographer) describes a workplace or office and only says a photographer *can* be hired for events. A [caterer tag](https://wiki.openstreetmap.org/wiki/Tag%3Acraft%3Dcaterer) describes catering generally; neither verifies a specific offered package.
- OSM attribution for any future derived dataset should read: **© OpenStreetMap contributors, data available under the Open Database License (ODbL)**, with links to [copyright/license](https://www.openstreetmap.org/copyright) and any required derivative database license. Review the [attribution guidelines](https://osmfoundation.org/wiki/Attribution_Guidelines) before redistribution.
- For each future record, preserve its exact OSM element URL or permission-based source URL. Do not turn generic site marketing, price bands, opening hours or repeated card ratings into verified vendor fields.

## Source suitability

Wedding Directory, EventPartner and WedHub are useful for market discovery or permission requests, but **not approved as pilot data sources** by this audit. OSM is legally usable under ODbL but the attempted retrieval did not succeed. The isolated CSV therefore remains a header-only template. A future vendor-submission form or permission-based export may provide the most useful prices, capacities, service areas and event-specific availability claims, each separately verified.
